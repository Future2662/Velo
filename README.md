You don't need IDM and BitTorrent anymore. Velo does both, in one clean app.

• Up to 32 connections per file
• Videos from 1,000+ sites, whole playlists, MP3/M4A audio, HLS streams
• Torrents and magnet links, and you choose which files to download
• Pause and resume, even after a restart. Expired links refresh automatically.
• Queues, schedules, folder rules, batch links, checksums, speed limits, Undo
• Browser extension for Chrome, Edge and Firefox (your sign-ins keep working)
• Private: cookies and passwords are encrypted by Windows
• Free forever. No ads, no trial, no licence key. MIT licensed and updated regularly.

Pair your browser in three steps:
1. Velo › Settings › Browser extension › Open folder
2. chrome://extensions › Developer mode › Load unpacked (pick the "chrome" folder)
   Firefox: about:debugging › Load Temporary Add-on
3. Click any download. It goes straight to Velo.
